# Lessons 15 — корзина Wildberries

Java 17+, Maven 3.9+, Google Chrome, Selenium 4 и JUnit 5. Проект создан в ветке `lessons-15` от `main` и не зависит от проектов предыдущих уроков.

## Проверяемый сценарий

`CartTest` выполняет полный сценарий через интерфейс сайта:

1. Открывает главную страницу и проверяет валюту RUB и пустую корзину отдельного тестового профиля.
2. Выбирает три разных доступных товара на главной. Для выбора используются названия бытовых товаров: например, шампунь, кофе, салфетки или контейнер. Карточки с сокращённым многоточием названием исключаются, чтобы затем сравнивать полные названия точно.
3. Перед добавлением запоминает артикул, название, текущую цену и количество каждого товара. Цены и артикулы не зафиксированы в коде.
4. Добавляет по одной единице каждого товара и после каждого нажатия ждёт увеличения счётчика корзины.
5. Переходит в корзину через ссылку в шапке и ждёт появления всех выбранных артикулов.
6. Проверяет набор артикулов, точные названия, количество каждого товара, число разных товаров, общее количество единиц, цену каждой позиции и общую сумму. Итог сравнивается отдельно с суммой цен из карточек и с суммой строк корзины.

Сопоставление товаров выполняется по артикулам, поэтому порядок строк в корзине не влияет на результат. Сравниваются текущие показанные цены с WB Кошельком; зачёркнутые старые цены в расчётах не участвуют. В гостевой версии корзины общая сумма отображается на кнопке «Войти и оформить» — тест читает цену с этой кнопки, не нажимая её.

После теста удаляются только товары, добавленные этим сценарием. Непустая корзина в начале считается ошибкой предусловия и не очищается автоматически. Заказ не оформляется, вход в аккаунт и оплата не выполняются.

## Запуск

Из корня репозитория:

```powershell
mvn -f wildberries-tests/pom.xml test
```

Из каталога `wildberries-tests` с видимым новым браузером:

```powershell
mvn test "-Dheadless=false"
```

По умолчанию создаётся отдельная сессия Chrome без окна. Selenium Manager подбирает драйвер; при первом запуске ему может понадобиться интернет для загрузки драйвера.

### Если Wildberries показывает проверку браузера

Сайт может блокировать автоматически открытый браузер сообщением «Подозрительная активность». Это ошибка доступа к сайту, и тест не подменяет её успешным результатом или пропуском.

Для запуска в отдельном, заранее открытом Chrome из каталога `wildberries-tests`:

```powershell
.\Start-TestBrowser.ps1
```

В появившемся окне дождитесь открытия Wildberries и при необходимости пройдите проверку сайта вручную. Используйте гостевой режим сайта, валюту RUB и пустую корзину этого тестового профиля. Затем выполните:

```powershell
mvn test "-DdebuggerAddress=127.0.0.1:9222"
```

Скрипт использует отдельный профиль `.browser-profile` внутри проекта и не использует данные вашего обычного браузера. Профиль исключён из Git. Не закрывайте тестовый Chrome до завершения запуска. Тесты работают обычными нажатиями Selenium; JavaScript используется для прокрутки.

Если нужен другой порт, передайте его скрипту и тестам:

```powershell
.\Start-TestBrowser.ps1 -Port 9223
mvn test "-DdebuggerAddress=127.0.0.1:9223"
```

Количество выбираемых товаров можно изменить параметром `-DproductsCount=4` (минимум два). Время ожидания элементов задаётся параметром `-DuiTimeoutSeconds=60`.

## Структура

Все Java-классы находятся в `src/test/java/ru/lesson`:

```text
base/
  BaseTest.java          запуск браузера, настройки, материалы при ошибках
  BasePage.java          общие ожидания, клики и прокрутка
components/
  ProductCard.java       чтение карточки и добавление товара
  CartItem.java          чтение и удаление конкретной строки корзины
config/
  SiteConstants.java     адрес сайта, пути страниц и валюта
  BrowserConstants.java  размеры окна и стандартное время ожидания
locators/
  CartLocators.java      общие селекторы корзины и счётчика в шапке
model/
  Product.java           неизменяемые данные товара и расчёт стоимости
pages/
  HomePage.java          главная страница и выбор товаров
  CartPage.java          корзина, ожидание товаров и чтение итогов
util/
  Money.java             разбор показанной рублёвой цены через BigDecimal
tests/
  CartTest.java          сценарий корзины на действующем сайте
  MoneyTest.java         14 проверок форматов цен и ошибочного ввода
```

`MoneyTest` проверяет обычные и неразрывные пробелы, копейки, обозначения рублей и отказ от неоднозначных цен. Для сумм используется `BigDecimal`, без округлений `double`.

Повторяющиеся пути `/lk/basket` и `/catalog/` задаются один раз в `SiteConstants`. Общие локаторы корзины находятся в `CartLocators`, а локаторы конкретных страниц и компонентов — в их собственных константах.

Только проверки формата цен, без браузера:

```powershell
mvn test "-Dtest=MoneyTest"
```

Только сценарий корзины в заранее открытом тестовом Chrome:

```powershell
mvn test "-Dtest=CartTest" "-DdebuggerAddress=127.0.0.1:9222"
```

Отчёты JUnit находятся в `target/surefire-reports`. При ошибке в сценарии снимок экрана, HTML и адрес страницы сохраняются в `target/failure-artifacts` до очистки добавленных товаров. Диагностические материалы и профиль браузера не попадают в Git.
